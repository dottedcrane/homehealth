# Casa Health — website

This repository hosts the **Casa Health** website (GitHub Pages): a marketing landing page,
the maintenance-hub usage guide, and the privacy policy for the offline Android
home-maintenance tracker.

- `index.html` — landing page (the maintenance hub's usage model, features, privacy promise)
- `usage.html` — full usage guide, including child-safety warnings
- `privacy.html` — privacy policy
- `styles.css` — shared styles (self-contained; no CDNs, no JS)

The previous contents of this repo (the HomeBase React-Native prototype README) are preserved
in git history.
